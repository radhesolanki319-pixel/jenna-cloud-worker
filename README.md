# ☁️ Jenna 24/7 Cloud Worker (Free Dots Engine)

Ye Jenna ka **Remote 24/7 Cloud Computer Container** hai jo OpenAI Dots AI jaisa real cloud compute deta hai — **100% Free, Zero Credit Card Required**!

---

## 🚀 2-Minute 1-Click Free Deployment on Hugging Face Spaces:

1. [huggingface.co](https://huggingface.co) par jao aur ek free account banao (agar nahi hai).
2. Upar right me **Create New Space** par click karo:
   - **Space Name:** `jenna-cloud-worker`
   - **SDK:** `Docker` (Blank)
   - **Hardware:** `CPU Basic` (16GB RAM, 2 vCPUs) — **Free 100%**
3. Files upload karo:
   - `Dockerfile`
   - `requirements.txt`
   - `app.py`
4. Space automatically build hokar **RUNNING** ho jayega!
5. Apne Space ka Public URL copy karo (e.g. `https://yourname-jenna-cloud-worker.hf.space`).
6. Jenna App me `🖥️ Cloud PC` kholo -> **Remote Cloud Worker** section me apna URL paste karke **Connect** dabao!
